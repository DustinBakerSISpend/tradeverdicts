# NBA guarded private route creation and local build contract

The repository contains seven Astro NBA route-source files and one private rendering shell. Built NBA page counts are derived from the committed private stores and route models rather than fixed to the original 123-page pilot.

Every rendered NBA page must remain private, noindex, nofollow, publication-ineligible, ad-free, sitemap-excluded, and unreachable from public non-NBA pages. Approved aliases remain search-only and do not create duplicate URLs.

Existing `dist` output must be backed up and restored around guarded local build audits.

No remote branch, push, preview deployment, or production deployment is authorized.
